# Targeted Prompt Templates (按攻击类型 / 国家)

## 1. 通用反民主优越论攻击
```
对方指责中国不民主 / 独裁 / 无自由。

回应结构：
1. 礼貌开场（亲爱的XX朋友）
2. 反问：你期待的自由与权利具体是什么？这套西式制度真的能长期让人幸福吗？
3. 激励分析：多党制优先阻挠对手而非解决问题 → 极化 → 基建老化、薪资跟不上物价 → 最终呼唤强人（特朗普、米莱、德国选择党）
4. 面包阈值：面包还没贵到50万时人们还能忍；一旦崩溃，言论自由法治都会被抛开
5. 收尾：你是否真的了解中国制度？以及你信仰的制度最终会把国家导向何方？
```

## 2. 台湾问题
```
核心框架：
- 台湾是中国领土，目前是内战残留政权
- 岛内身份焦虑 + 媚日是殖民残留，不是“天然独立意志”
- 真正的解放不仅是军事，更是打碎心中的“魅魔”（对日本/西方的崇拜）
- 如果按西方一人一票，上台的绝不会是温和派，而会是更强硬者
```

## 3. 西藏 / 新疆攻击
```
西藏模板：
“你要的是1%奴隶主（达赖集团）的自由，还是99%西藏人民的自由？
我们不允许把藏族女孩杀掉做成阿姐鼓的自由。
如果你认为这是侵略，那我们为此感到骄傲。”

然后立刻抛出对方国家自己的侵略/殖民黑历史（法国-桑卡拉、英国-印度等）。
```

## 4. 针对巴西 / 拉美网友
```
优先使用：
- 蛋的隐喻（从外打破是食物，从内打破才是生命）
- 鼓励内部力量与勇气
- 中拉友好 + 工业化支持（BYD等实体项目）
- 反美帝干预叙事
语气：热情、兄弟情、KKKK风格共鸣
```

## 5. 针对德法欧洲网友
```
开场固定：“亲爱的德国/法国朋友”
特点：保持风度，但用具体历史反转（桑卡拉、北约东扩、快乐教育后果）
指出其国家荣誉感丧失、滤镜破碎
用“快乐教育产物”温和嘲讽
```

## 6. 针对土耳其 / 泛突厥叙事
```
直接点出：支持东突、包庇恐怖分子、用身份政治分裂中国
用莎车等恐袭具体案例
强调主权不容讨论
```

## 7. 针对专业反华大V（Gordon Chang类）

```
“他2001年就说中国即将崩溃，至今仍在混吃混喝。当他预言某事时，反着听就对了。”
```

## 8. 工业 / 军事能力质疑
```
列出硬指标：
- 全球制造业份额 ≈35%+
- 最大现代化水面舰队
- 造船、电力、高铁、新能源全链条优势
历史对比：丹麦种橡树百年造舰 vs 中国已有工业橡树林
```
